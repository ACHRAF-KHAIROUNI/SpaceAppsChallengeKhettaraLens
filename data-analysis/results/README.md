# Results

Files here are **produced by the notebook**. Do not edit them by hand: re-run the notebook and upload the new versions.

| File | What it is | Used for |
|---|---|---|
| `trend_dashboard.html` | Interactive dashboard (download and open in a browser) | Exploring |
| `trend_results.csv` | What / where / by how much / significant | **The single source of numbers** |
| `annual_series.csv` | Annual values for each variable and site | Re-drawing charts |
| `trend_summary.png` | Slope per decade per site, dark = significant | Slides |
| `variable_links.png` | Correlations between variables at one site | Slides |
| `team_bsi_vs_rain.png` | Wet/dry months vs bare soil index | Slides |
| `README.md` (generated) | Sources, method, significant trends, limits | Proof for the jury |
| `data_provenance.csv` | Product, version, period, DOI of each source | Proof for the jury |

## How to update
1. Run the notebook to the end.
2. Download `trend_results.zip` (notebook step 12, option B) and unzip it.
3. Upload the files to this folder on GitHub (*Add file → Upload files*). Existing files are replaced.

> Until the notebook has been run once, this folder only contains this README.
